# 定理 C₂/C_n: 反復ループ胞体上の再パラメータ化コヒーレンス(M2、2026-07-28)

次元1の再パラメータ化コヒーレンス定理(docs/ReparamCoherence.md:
generic path 上の接続代数の作用 = 自由 De Morgan 代数、忠実)の高次元化。
機械証拠は `LibSquares.lean`(全 guard 通過)。

## 0. 設定

文脈 Γ = (A : U, a : A, q : Loopⁿ) — ここで Loop¹ := Path A a a、
Loop^{k+1} := Path (Loop^k) refl_k refl_k(refl_k は k 段の refl 塔)。
m 個の区間束縛 i⃗ = (i₁..i_m) と組 φ⃗ = (φ₁,…,φ_n) ∈ DM(i⃗)ⁿ に対し

  S(φ⃗) := ⟨i₁⟩…⟨i_m⟩ q(φ₁)(φ₂)…(φ_n)

(q(φ) は端点注釈つき papp)。n = m = 2 が正方形の場合(C₂)。

**定義(退化)**: φ⃗ が**退化** :⟺ ∃k. φ_k ∈ {0, 1} **自由 De Morgan
代数の意味で**(すなわち dnf(φ_k) = [] または [[]])。

この定義が「カーネルの崩壊条件と正確に一致する」ことが証明の土台:
`vpapp`(Semantics.lean、中立 head の節)は `r.isZero / r.isOne` で
崩壊し、`isZero/isOne` は **DNF ベース**(Interval.lean:166–168:
`dnf r == []` / `== [[]]`)。すなわち構文形でなく自由 DM 代数の元と
しての 0/1 性で判定される。

## 1. 補題(本体値の計算)

generic レベル l⃗ で S(φ⃗) の本体 q(φ₁)…(φ_n) を評価すると:

1. **φ₁ ∈ {0,1}**: 内側 vpapp が崩壊し q@φ₁ = refl 塔の値(vplam)。
   以後の papp は capp(クロージャ適用)で計算し、最終値は **a**
   (どの φ_k にも依らず)。
2. **φ₁ 非端点、∃k≥2 最小の φ_k ∈ {0,1}**: k−1 段の中立 spine が
   でき、k 段目の vpapp(中立 head)が**格納された端点注釈**
   (refl 塔ないし a)を返し、以後 capp で **a** に計算。
3. **全 φ_k 非端点**: 完全な n 段中立 spine
   papp(…papp(q, e⃗₁, φ₁)…, e⃗_n, φ_n)(e⃗_k は型が定める端点注釈値)。

まとめ: **本体値 = a ⟺ φ⃗ 退化**; 非退化なら n 段 spine で、区間引数
列がそのまま保持される。∎

(機械対応: 1 = `sq2DegFstD`、2 = `sq2DegSndD`、退化クラスの一点性
= `sq2DegCrossD`。)

## 2. 定理 C_n

境界が整合する(比較が型付けできる)φ⃗, ψ⃗ について:

  S(φ⃗) ≡alg S(ψ⃗) ⟺ (φ⃗, ψ⃗ とも退化) ∨ (とも非退化 かつ φ⃗ = ψ⃗ in DM(i⃗)ⁿ)

とくに退化 square はすべて定数 square ⟨i⃗⟩a に等しく、非退化な組の上では
作用は**忠実**(単射)である。

### 証明

conv は m 個の区間 binder を convIBinder で generic レベルに開き、
本体値(補題 1)を比較する。

(⟸) とも退化: 両本体は同一の generic 中立変数 a — 受理。
とも非退化で φ⃗ = ψ⃗: spine は段ごとに head(q、同一レベル)・端点注釈
(同一の refl 塔 / a、構造比較で等しい)・区間引数(r.equiv = dnf
等式; dnf は自由 DM の正準形なので φ_k = ψ_k から等しい)— 受理。

(⟹) conv 受理と仮定。場合分け:
- 両本体 a: 補題 1 より両者退化 ✓。
- 両本体 spine: convNe の papp 節は spine を段ごとに比較し、区間引数は
  r.equiv(dnf 等式 — 自由 DM に対し健全**かつ完全**)を要求。
  よって全 k で φ_k = ψ_k ✓(非退化も補題 1 より)。
- 混在(a vs spine): convNe は変数 head と papp head を区別し拒否 —
  受理と矛盾。∎

### 決定可能性・無条件性

比較はすべて minimal core の内部(Π 型も宇宙も不要 — 文脈は A, a, q
と Path 型のみ)なので、v14 の Theorem (Canonicity regained)系の
core 停止性・決定可能性により、上のすべての言明は**無条件の決定可能な
事実**である(dim-1 定理の時点では「アルゴリズム的主張」の但し書きが
必要だった — 端点盲目不変量の副産物としてこの但し書きが消えた)。

## 3. 系(次元 2 の風景)

C₂(n = m = 2)+ LibSquares の機械証拠から:

1. **DM² の忠実な strict 作用**: 冪等・対合・吸収・De Morgan 双対など
   自由 DM 代数の全法則は座標ごとに定義的
   (`sq2IdemD`/`sq2InvolD`/`sq2AbsorbD`/`sq2DeMorganD`)。
2. **転置は strict でない**: (j, i) ≠ (i, j) は非退化な相異なる組
   ⟹ `⟨i⟩⟨j⟩ q(j)(i) ≢ ⟨i⟩⟨j⟩ q(i)(j)`(`#guard` 負例+対照)。
   これは **Eckmann–Hilton が weak でしか成立しない**ことの、
   判断的等式レベルでの正確な影(交換には hcomp 生成構造が必須)。
3. **次元 2 の排中律なし**: i∧¬i は自由 DM の端点でない ⟹
   (i∧¬i, j) は非退化 ⟹ 定数 square と分離
   (`sq2LEMCtrlD` + 負 `#guard`)。すべての**角**が 0 でも square は
   退化しない — 自由 De Morgan 代数の非ブール性が次元 2 でも
   定義的に見える。

## 4. トラック C の位置づけと次の一手

- **確定した描像(次元 ≤ 2)**: 反復ループ胞体への「strict に作用する
  もの」= 自由 De Morgan 代数の座標ごとの作用+端点退化崩壊、
  **それだけ**(転置・交換は含まれない)。cubical 型の弱 ω-亜群構造の
  strict 層の特徴付けが、胞体作用のレベルで次元 2 まで完了。
- C_n は一様に証明済みなので、実質的な残りは:
  (C-3) **複数の独立な胞体**(q₁, q₂ の混在項: whisker・水平合成の
  strict/weak 分類 — EH の週化の更なる精密化)、
  (C-4) これらを束ねた「strict 層 = 自由 DM クローン作用」型の
  特徴付け定理の一般次元形と、コヒーレンス公理化への含意の整理
  (論文候補: 次元 1 の定理(jrefl 論文掲載)+ C_n + 分類系を
  まとめた track-C 論文)。

## 5. C-3: 複数胞体 — ウェッジ定理(2026-07-28 追記)

文脈 Γ に複数の generic 胞体 q₁ : Loop^{n₁}, …, q_s : Loop^{n_s}
(共通の底点 a)がある場合の、純粋再パラメータ化層の完全な記述。

**観察(構文的)**: Kan 操作(transp/hcomp)を使わない限り、m-立方体の
本体(型 A の項)として書けるのは
- 底点 a、または
- **ちょうど一つの**胞体の完全適用 q_t(φ₁)…(φ_{n_t})
のいずれかに評価される項だけである(本体は単一項であり、区間で
場合分けする構文が存在しないため、二つの胞体を一点で「混ぜる」ことは
できない)。

**定理 C-multi(ウェッジ)**: 複数胞体文脈上の strict m-立方体層は、
各胞体の自由 DM^{n_t} 作用(定理 C_n)の**ウェッジ**(退化した一点 =
定数立方体でのみ貼り合わせた非交和)である。すなわち
S_t(φ⃗) ≡alg S_u(ψ⃗) ⟺
(両者退化 — 胞体が異なってもよい)∨(t = u かつ とも非退化 かつ φ⃗ = ψ⃗)。

*証明*: 補題 1(本体値の計算)は胞体ごとにそのまま適用できる。
退化なら本体は共通の a(胞体によらない — これがウェッジの貼り合わせ
点)。非退化なら n_t 段の中立 spine で、convNe は
(i) **head 変数のレベル**(q_t vs q_u、t ≠ u で不一致)、
(ii) **spine の深さ**(n_t ≠ n_u なら形が不一致)、
(iii) 各段の区間引数(r.equiv)
を順に検査するから、受理 ⟺ t = u ∧ φ⃗ = ψ⃗。∎

機械証拠(LibSquares、全 guard 通過):
- `sqxDegD`: ⟨i⟩⟨j⟩ q(0)(j) ≡ ⟨i⟩⟨j⟩ r(i)(1) — **異なる胞体の退化
  square が等しい**(ウェッジ点の共有)
- 負 guard: ⟨i⟩⟨j⟩ q(i)(j) ≢ ⟨i⟩⟨j⟩ r(i)(j) — 同一式でも胞体が
  違えば分離(head 分離)
- `sqxDepthCtrlD` + 負 guard: ⟨i⟩⟨j⟩ p((i∧¬i)∧(j∧¬j)) は SqT で
  well-typed(4 辺すべて 0 に落ちるが内部は自由 DM で非零!)かつ
  ⟨i⟩⟨j⟩ q(i∧¬i)(j∧¬j) と分離 — **spine 深さ(1-胞体 vs 2-胞体)に
  よる分離**。1 変数式 (i∧¬i)∧(j∧¬j) の例は「全辺が退化するのに
  内部が非退化」という自由 De Morgan 代数の非ブール性の 2 次元的
  発現でもある。

**含意(トラック C の物語)**: whiskering・水平/垂直合成・交換など、
複数胞体を**組み合わせる**演算はすべて hcomp 生成(= weak 層)である
ことが、これで「定義により」ではなく「定理として」言える: strict 層は
ウェッジであり、胞体間の相互作用を一切含まない。よって
- 弱 ω-亜群構造のうち strict なのは「各胞体の自由 De Morgan 再
  パラメータ化+全胞体共通の退化点」**のみ**;
- Eckmann–Hilton・交換法則・合成の全коherence は必然的に weak 層に
  住む(No-go 定理がその「なぜ」を与える: それらの等式的 strict 化は
  hcomp-regularity を再導入する)。

これで C-4(特徴付け定理の一般形)の材料が揃った: 「strict 層 =
胞体ごとの自由 DM クローン作用のウェッジ」を、任意 arity・任意個数の
胞体で述べる定理が track-C 論文の主定理候補である。

## 6. C-4: 一般特徴付け定理 — strict 層は De Morgan 球面のウェッジ(2026-07-28 追記)

### 6.1 De Morgan 立方体圏と作用

**定義(De Morgan 立方体圏 𝔻)**: 対象は [m](m ≥ 0)、射
𝔻([m],[n]) := DM(i₁,…,i_m)ⁿ(n 組の式)、合成は式の代入、恒等射は
生成元の組 (i₁,…,i_n)。これは接続(∧,∨)・逆(¬)・対角(変数の
重複)・退化(定数)をすべて含む立方体圏 — 自由 De Morgan 代数の
Lawvere 理論の双対 — である(接続付き立方体圏の系譜: Grandis–Mauri)。

arity n の generic 胞体 q は各 [m] に作用
A_q : 𝔻([m],[n]) → (m-立方体)/≡alg、φ⃗ ↦ ⟨i⃗⟩ q(φ⃗) を定める。

**補題 6.1(作用の strict 性、機械検証)**:
- **単位律**: A_q(id) = ⟨i⟩⟨j⟩ q(i)(j) ≡ q(入れ子の path η;
  `sqEtaD`)。
- **合成律**: A_q(φ⃗) の再パラメータ化 = A_q(φ⃗ の代入)
  (papp∘plam の β = 式代入; `sqCloneCompD`:
  (⟨u⟩⟨v⟩q(u)(v))(i∨j)(i∧j) ≡ q(i∨j)(i∧j))。
すなわち A_q は**定義的等式のレベルで**関手的(strict なクローン作用)。

**補題 6.2(部分適用の還元)**: 高次型 Loop^d 値の m-立方体
(部分適用 ⟨i⃗⟩ q(φ₁)…(φ_j)、j = n − d)の比較は、conv の型主導 η に
より d 個の fresh generic 座標を末尾に付けた完全適用の比較に一致する。
generic 座標は決して端点でないから、部分適用の分類は末尾を「常に
非退化な相異なる generic」とした C_n に帰着する。
(機械対応: 対角 `sqDiagCtrlD` — [1]→[2] の対角射 i↦(i,i) の作用 —
と、対角 vs 反対角の分離の負 guard が j=1, d=1 の実例。)

### 6.2 面因子化と球面

**補題 6.3(退化 = 面因子化)**: 組 φ⃗ が退化(∃k. φ_k ∈ {0,1})
⟺ 射 φ⃗ : [m]→[n] がある面射 δ_k^ε : [n−1]→[n] を通して因子化する。
このとき A_q(φ⃗) = 定数立方体(補題 1)。

**定義**: 𝔻(−,[n])/∂ := 表現可能関手の、面因子化する射を一点に潰した
点付き商 — **De Morgan n-球面**。

### 6.3 定理 C-4(一般特徴付け)

generic 胞体 q₁,…,q_s(arity n₁,…,n_s、共通底点)をもつ文脈上で、
純粋再パラメータ化層(Kan 操作を含まない definable 立方体の全体)は、
≡alg で割ると、各 [m] で自然に

  ⋁_{t=1..s} 𝔻([m],[n_t]) / ∂   (点付きウェッジ)

に同型である。すなわち **strict 層は De Morgan 球面のウェッジ**。
自然性(再パラメータ化との両立)は補題 6.1、点は共通の定数立方体、
単射性は C_n(補題 1+convNe)、胞体間の分離はウェッジ定理(§5)、
definable 層が作用の像で尽きることは §5 の構文的観察+補題 6.2。∎

すべての言明は minimal core の内部なので、v14 の端点盲目定理により
無条件・決定可能。

### 6.4 含意と論文化(track-C 論文の骨子)

- **コヒーレンス公理化への寄与**: cubical 型理論における「型は弱
  ω-亜群」構造のうち、**判断的等式が自動で供給する厳密部分の完全な
  記述**が得られた: 生成胞体上では自由 De Morgan 立方体圏の作用
  (球面のウェッジ)であり、それ以外(合成・交換・whisker 等)は
  No-go 定理により必然的に weak。これは「どこまでが strict になり
  得るか」の上限を計算的に確定する定理である。
- 論文骨子: (1) 𝔻 と作用の定義、(2) 補題 6.1–6.3(機械検証つき)、
  (3) C_n・ウェッジ・C-4、(4) weak 側の必然性(No-go の引用)、
  (5) カタログとの照合。jrefl 論文の dim-1 定理を特殊例として
  包含。投稿先候補: 圏論寄り(ACS/TAC 系)または型理論会議。
