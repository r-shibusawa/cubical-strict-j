# Kleene 補間理論(証明ノート、2026-07-31)

論文 docs/paperI/kleene.{tex,pdf} の証明ノート。論文6(ファイバー)・論文7(strict 層)の枠組みを
Kleene 立方体圏に移植し、Dedekind と De Morgan の間の正確な補間を得る。

## K1. 表現定理(数値確認済み・証明骨子あり)

**定理**: 自由 Kleene 代数 KL(n) ≅ **非混合点集合 U_n 上の単調関数**。
U_n := リテラル立方体 Q_n から「混合点」((0,0) ペアと (1,1) ペアが
共存する点)を除いたもの。

証明骨子: (a) 制限 monotone(Q_n) → monotone(U_n) は全射 De Morgan 準同型
(U_n は ¬ の対称で閉、最小拡張が切断)。(b) monotone(U_n) は Kleene 則を
満たす(α ∈ x∧¬x なら α に (1,1) ペアがあり、非混合性から (0,0) ペアが
なく α ∈ y∨¬y)。(c) 3 値評価の二重プローブ: v ∈ 3^n に対し u を一律に
(0,0) とした v_low と一律に (1,1) とした v_high は**常に非混合**であり、
ĝ(v) = (g(v_low), g(v_high)) の対応で monotone(U_n) ↪ Fun(3^n, K3) が
単射(非混合点 α は α = v_low または v_high として回収できる)。
GWW 2003 の「自由 Kleene = K3^{3^n} の生成部分代数」と併せて同型。∎

**数値確認**: |monotone(U_n)| = 6, 84, 43918(n=1,2,3)=
Berman–Mukaidono の自由 Kleene 濃度と完全一致。|U_n| = 4, 14, 46。

## K2. ファイバー定理(Kleene 版)

U_n の「見えない点」(全面制限が見ない点)= 非混合対角点 = **{⊥, ⊤}
の 2 点のみ**(他の対角点はすべて混合で U_n に存在しない)。
⊥ < ⊤ は比較可能なので、ファイバーの差 D は反鎖として
D ∈ {∅, {⊥}, {⊤}}。よって:

**定理**: KL(n) の境界ファイバーはサイズ ≤ 2 で、非単元ファイバーは
**n によらずちょうど 2 個**(ゼロ境界 {0, δ⊤} とトップ境界 {1∖⊥, 1})。
恒等式 **B_K(n) = FK(n) − 2**。

**census**: n=1: 4 境界 {1:2, 2:2}; n=2: 82 境界 {1:80, 2:2};
n=3: 43,916 境界 {1:43914, 2:2} ✓ 恒等式成立。
(n=2 で B_K = B_DM = 82 は偶然でない: n=2 の混合点は対角 2 点のみで
面点 poset が一致するため。n≥3 で分岐: 43,916 vs 4,829,136。)

## K3. Kleene 立方体圏

- 非冪等完備: |KL(1)| = 6 = |DM(1)| なので論文7の x∨¬x 非分裂証明が
  **逐語的に**通る ⟹ 非 EZ。
- Karoubi 包絡 = (有限射影 Kleene 代数)^op、特徴づけは
  Bova–Cabrer Thm 12(K1, K2, M2, M3)。

## K4. defect・coherence の移植(全数検証済み)

理論の移植は「見えない点の集合」を {⊥,⊤} に置き換えるだけ
(比較可能対角点間の面点補題は ⊥<⊤ に対して成立)。
- **defect 公式**: KL(2) 全 84 元で 公式 = 総当たり最小(84/84)、
  ズレ反鎖 A_g ⊆ {⊥,⊤} を全ケースで確認。
- **coherence 二分定理**: 正確(incoherent = criterion-hit が全置換
  クラスで一致)。破れは接続・対角で各 2 元(極元)のみ、反転・x∧¬x は 0。
- Kleene 置換は U を保存(F(v_low) = (t(v))_low — 意味論的に明らか、
  機械 assertion でも確認)。

## K5. 三理論補間表(論文8の主表)

| 理論 | 見えない点 | ファイバー | 非単元ファイバー数 | coherence 破れ |
|---|---|---|---|---|
| Dedekind(対合なし) | ∅ | 全て単元 | 0 | なし(r = id) |
| **Kleene** | {⊥, ⊤} | ≤ 2 | **ちょうど 2(n 非依存)** | 極元のみ(各写像 ≤ 2) |
| De Morgan | 対角 2^n 点 | ≤ 2^C(n,⌊n/2⌋) | n=3 で 34.5% | n=3 で 14.5% |

**標語候補: 対合の「弱さ」の 3 段階が、EZ からの距離(充填の
非一意性と骨格の非自然性)を正確に定量化する。**
Kleene 則は「ほぼ EZ」— 例外は正確に 2 つの極ファイバー。

## 完全性定理(2026-07-31 改訂で論文に追加)

**定理**: 区間 signature({∧,∨,¬} の部分集合)が対合と接続の両方を
含まない限り、自由代数の境界ファイバーはすべて単元。よって実現可能な
ファイバー挙動は 自明 / 極 2 個(Kleene)/ Sperner 極値(De Morgan)
の 3 つで尽きる(¬+片接続 ⟹ De Morgan 律で他方定義可能 ⟹ 完全
signature に帰着 ⟹ Kalman の 3 択)。

部分 signature の機械確認: Dedekind n≤3(6, 20 元)、∧のみ n≤3
(5, 9 元)、¬のみ n=2(6 元)— 全ファイバー単元。
証明の核: これらの表現では全評価点が面到達可能(2 面分解ほか)。

**標語: ファイバーの自由は対合×接続の相互作用からのみ生まれ、
生まれれば Kalman の 3 段階で尽きる。**
