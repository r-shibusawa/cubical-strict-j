# De Morgan cubical sets の strict 層(証明ノート、2026-07-31)

論文 docs/paperH/strictdm.{tex,pdf} の証明ノート。前提は
docs/DMFiber.md(境界ファイバー定理)。数値はスクリプトで再現可能。

## 1. Karoubi 包絡

- **非冪等完備**: e = (x ↦ x∨¬x) : [1]→[1] は冪等(吸収律)だが
  分裂しない。証明: e = s∘p, p∘s = id_[k] とすると DM(k) が DM(1)
  (6 元)のレトラクト ⟹ k ≤ 1; k=0 なら e* が定数(x∨¬x ∉ {0,1} に
  矛盾)、k=1 なら e* が単射(e*(x) = e*(x∨¬x) に矛盾)。
  ⟹ 非 generalized-Reedy ⟹ 非 EZ。
- **Kar(□_DM) ≃ (有限射影 De Morgan 代数)^op**: □_DM = (自由代数)^op、
  多様体では冪等分裂・自由のレトラクト = 射影・局所有限なので
  有限生成射影 = 有限。射影性の組合せ的特徴づけは
  **Bova–Cabrer (Order 31, 2014) Thm 11**: 双対対合 poset (P,≤,i) が
  (M1) 束、(M2) x≤i(x) ⟹ ∃y≥x, y=i(y)、(M3) {x : x≤i(x)} が 3-完備。
  cubical 文献(Sattler 1805.04126 = Dedekind、Campion 2303.06206 =
  Boolean)と unification 文献の橋は本論文が初。Kleene 版は同
  Thm 12 で同様。

## 2. ズレの反鎖公式

**定理**: A_g := {g の極小点 ∩ 対角点}(反鎖)とすると
r(g) := g ∖ A_g は**一段で**境界ファイバーの最小元。
(新たな対角極小点は生じない — 比較可能対角点間の面点補題。)

**系**: 置換 f・境界最小 φ に対するズレ =
A_{f*φ} = {α 対角 : F(α) ∈ φ、全下被覆 β⋖α で F(β) ∉ φ}。
補正は同一ブールファイバー内、χ median シリンダーが標準ホモトピー。

**全数検証**: n=2 全 168 元・転送 410 インスタンス(非空ズレ 81)、
n=3 全 7,828,354 元で公式 = ファイバー最小(不一致 0)。

## 3. coherence 二分定理

**定理**: 次は同値 —
(i) r(f*g) = r(f*(r g))、(ii) ∂(f*g) = ∂(f*(r g))、
(iii) F(Face(Q_m)) ∩ A_g = ∅。
各含意 2 行(鍵: 最小元は自分の境界を決定する)。

**生成子の分類**: 面・対称・反転・x↦x∧¬x は面点を面点に送る ⟹
無条件 coherent(合成で閉じる広い部分圏 □_DM^fp 上で r は厳密自然)。
退化・接続・対角は面点を対角点に送りうる ⟹ 条件付き(二分定理が
正確)。特に**退化も条件付き**: シリンダー g×I の新しい面は g 自身
なので、A_g ≠ ∅ なら r(g×I) ≠ r(g)×I — **最小骨格はシリンダー
安定でない**。

**全数検証(n=3)**: 対角(x1:=x2)と接続(x1:=x1∧x2)で
(i)(ii)(iii) の成立集合が **1,133,756 で完全一致**、反転は 0。
n=2 の例外は極元 2 つ(1 と x∧¬x∧y∧¬y)のみ = 到達可能対角が
極に限られるため。

## 4. 結語(論文の位置づけ)

- Higgins 2005 / Steiner 2006 の thin filler 一意性は strict ω-圏の
  合成構造+EZ 正規形に依存。Steiner は weak 設定での非一意性を予想
  していた — De Morgan strict 層はその実現(合成なし・ブール torsor)。
- **標語: EZ 正規形なきところで thinness は property たり得ない —
  最小充填+ズレ反鎖+median 補正が、それを置き換える最小の structure。**
- 今後: AWFS への組織化(χ 補正と分配則の検証)、Kar(□_DM) 上の
  presheaf、Kleene 補間。
