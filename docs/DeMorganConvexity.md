## 1. 補間補題

**補題 1(補間子)**: φ, φ′ ∈ DM(i⃗) について
χ(k) := (φ∧¬k) ∨ (k∧φ′) ∨ (φ∧φ′) は
(a) χ(0) = φ、χ(1) = φ′;
(b) 任意の面 f で φ|f = φ′|f = ρ ならば χ|f = ρ(k-定数)。

*証明*: (a) χ(0) = (φ∧1)∨0∨(φ∧φ′) = φ∨(φ∧φ′) = φ(吸収:
φ∧φ′ ≤ φ)。χ(1) 対称。(b) χ|f = (ρ∧¬k)∨(k∧ρ)∨(ρ∧ρ) =
(ρ∧¬k)∨(ρ∧k)∨ρ = ρ(吸収: 前 2 項 ≤ ρ)。∎

**補題 2(第 3 項の必然性)**: 素朴な χ₀(k) := (φ∧¬k)∨(k∧φ′) は
面上で ρ∧(k∨¬k) に制限され、k-自由な ρ ≠ 0 について
ρ∧(k∨¬k) = ρ ⟺ ρ ≤ k∨¬k ⟺ ρ の各 clause が k か ¬k を含む ⟺ 偽。
すなわち**排中律の不在ゆえ素朴な凸結合は必ず境界で壊れる**。
機械証拠: 負 guard(H₀ の型検査失敗)。∎

## 2. 同一胞体内: fiber の strict 収縮可能性

**定理 3**: 胞体的文脈上、同一胞体 c 由来の 2 つの同一境界充填
F = A_c(φ⃗)、F′ = A_c(φ⃗′)(m-立方体)は strict ホモトピー rel
boundary で結ばれ、さらに fiber(c-由来の同一境界充填全体)は
全階層で strict に連結(strict 収縮可能)。

*証明*:
(i) **境界一致 ⟹ 制限一致**: 実現定理の単射性(realization 論文 Thm)により、
面の値の一致は面制限 tuple の自由 DM での文字通りの一致を強制する
(単一胞体の実現は完全表現可能関手で単射; 面の値 = 面制限の像)。
(ii) **1 段**: 各座標に補題 1 の χ_t を適用。χ⃗ の k-端は φ⃗/φ⃗′
(補題 1a)、各面では制限一致(i)ゆえ k-定数(補題 1b)⟹
H := A_c(χ⃗)(k を外側 binder に)は Path(境界型) F F′ に型付く。
(iii) **高次段**: F, F′ 間の 2 つのホモトピー H = A_c(χ⃗)、
H′ = A_c(χ⃗′) は (m+1)-立方体として全面の制限が一致する
(k-端面: 双方 φ⃗/φ⃗′; 他の面: 双方とも共通境界の k-定数拡張 —
(i) を (m+1) 次元で再適用)。よって再補間でき、帰納的に全階層で
連結。∎

## 3. 胞体横断: 共有部分複体経由の連結(機械ジグザグ)

同一境界の充填が異なる胞体に由来する場合(実現定理より、境界は
双方が生成できる**共有部分複体**上に載る)、単一の strict 立方体は
単一胞体材料なので直接のホモトピーは存在しない。しかし:

**定理 4(変形)**: S1 = A_{Q1}(E₀, j)(E₀ = i∨¬i∨j∨¬j)と
S2 = A_{Q2}(D₀, j)(D₀ = i∧¬i∧j∧¬j)— 共有辺 m 上に境界が完全に
載る 2 充填 — は、いずれも辺 square Sm = ⟨i⟩⟨j⟩m(j) に strict に
変形する:
- ⟨k⟩⟨i⟩⟨j⟩ Q1(E₀∨k)(j) : Path SqM S1 Sm(k=1 で E₀∨1 = 1、
  Q1@1 ≡ m — attachment)。境界 k-定数: E₀ の全面制限は 1 で
  1∨k = 1。機械: `mixDeformQ1D` ✓
- ⟨k⟩⟨i⟩⟨j⟩ Q2(D₀∧¬k)(j) : Path SqM S2 Sm(k=1 で 0、Q2@0 ≡ m)。
  機械: `mixDeformQ2D` ✓

よって **S1 ⇝ Sm ⇜ S2 のジグザグで胞体横断成分も strict に連結**。

*一般化(証明スケッチ)*: F = A_c(φ⃗) の境界が共有部分複体上に
載る ⟺ 各面制限が「共有面を通る面因子化」の値を持つ。単射性より
面制限は当該面因子化 tuple と一致し、とくに c の共有面方向の座標
φ_t の全面制限は端点 ε(共有面の向き)である。すると補題 1 を
φ_t と定数 ε に適用でき(制限一致 ✓)、F は共有面材料の充填に
変形する。共有材料内の充填同士は定理 3(1 段下の胞体で)により
連結。帰納で:

**定理 5(fiber の大域 strict 収縮可能性)**: 胞体的文脈上、任意の
境界の strict 充填 fiber は(空でなければ)strict ホモトピーの
全階層で連結である。

*証明*: 充填を胞体の次元で層別。同一胞体内は定理 3。異なる由来は
上の変形で共有部分複体へ降下し(次元帰納)、そこで定理 3。高次段は
定理 3(iii) と同じ再補間。∎

## 4. まとめ(convexity 論文の主定理群、確定形)

1. **補間定理**(補題 1+定理 3): strict 充填の一意性は成立しない
   (realization 論文)が、**up to strict homotopy では一意** — Kan の
   「up to homotopy 一意性」の完全な strict 平行。
2. **必然性**(補題 2): 補間子の第 3 項は排中律の不在の正確な
   代償(機械)。「De Morgan 凸結合」は (φ∧¬k)∨(k∧φ′)∨(φ∧φ′) が
   正しい形。
3. **大域収縮可能性**(定理 5): 胞体横断も共有部分複体経由で連結
   (機械ジグザグ)。
4. 命名: fiber 上のこの canonical 構造を **De Morgan 凸性**と呼ぶ。
   接続代数の「強い(Kleene 型)凸結合」が strict 世界の
   ホモトピー論を丸ごと供給する、が convexity 論文の一行要約。
