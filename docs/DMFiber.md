# 自由 De Morgan 代数の境界ファイバー(証明ノート、2026-07-30)

論文 docs/paperG/dmfibers.{tex,pdf} の証明ノート。数値はすべて
scripts/dmfiber.py・dmfiber3.py・dmfiber_boundaries.py で再現可能。

## 0. 設定

DM(n) = n 生成自由(有界)De Morgan 代数。古典的表現
(Balbes–Dwinger Ch. XI; Gehrke–Walker–Walker 2003;
Movsisyan–Aslanyan, Demonstr. Math. 47(2) 2014, Thm 3.2 + Cor 2.5):
束簡約は 2n 個のリテラル (x_i, x̄_i) 上の自由有界分配束 ≅ リテラル立方体
{0,1}^{2n} 上の単調ブール関数(上集合)。|DM(n)| = M(2n)(Dedekind 数)。

- **面制限** x_i:=e: ペア (x_i,x̄_i) を (0,1)(e=0)/(1,0)(e=1)に固定
  → DM(n−1) への束準同型。**境界** = 2n 面の組。
- **面点** = あるペアが (0,1) か (1,0) の点。**対角点** = 全ペアが
  (0,0) か (1,1) の点(≅ {0,1}^n、2^n 個)。面はちょうど面点だけを見る。

## 1. 構造定理

**定理.** 境界写像の各ファイバーは区間 [m, M] であり、
D := M∖m は**対角点の反鎖**、ファイバー ≅ 2^D(ブール束、補元は
g ↦ m∨(M∧gᶜ))。逆に**任意の対角点反鎖 D が実現可能**。したがって
最大ファイバーは **2^{C(n,⌊n/2⌋)}(Sperner の定理)**。

証明の骨子:
1. (区間)面制限は単調。bnd(m)=bnd(M)、m ≤ g ≤ M なら挟み撃ちで
   bnd(g) 一致。ファイバーは ∧,∨ 閉なので m,M 存在。
2. (D は面点を含まない)c ∈ D が面点なら当該面で M と m の面が相違。
3. (D は反鎖)p < q ∈ D とする。対角点どうしなので、差のあるペア i で
   p_i=(0,0), q_i=(1,1)。c := p のペア i を (0,1) に上げた点。
   p < c ≤ q、c は面点。M 上閉 & p∈M ⟹ c∈M; c 面点 ⟹ c∉D ⟹ c∈m;
   m 上閉 & c ≤ q ⟹ q∈m。q∈D と矛盾。∎
4. (ファイバー ≅ 2^D)中間上集合 g ↔ g∖m ⊆ D、D の真上は 3 の議論で
   m に入るため任意の部分集合が上集合を与える。
5. (実現)対角反鎖 D に対し m := (D の各点の真上の面点)の上閉包、
   M := m ∪ D。
6. (最大)対角点 ≅ {0,1}^n の反鎖の最大サイズは C(n,⌊n/2⌋)。

**機械検証**:
- n=1: |DM|=6, B(1)=4, ファイバーサイズ分布 {1:2, 2:2}
- n=2: |DM|=168, B(2)=82, 分布 {1:28, 2:38, 4:16}
- n=3: |DM|=7,828,354, B(3)=4,829,136,
  分布 {1:2,698,202, 2:1,747,364, 4:358,284, 8:25,286}
- ブール性: n=3 の全 2,130,934 非単元ファイバーで補元式が成立(失敗 0)
- n=4: Sperner 構成(C(4,2)=6 反鎖)で 2^6=64 ファイバーを直接構成・
  全 64 部分集合の境界一致を検証 ⟹ 最大 64 確定
- 恒等式 M(2n) = Σ_境界 2^{|D|}: 28+76+64=168、
  2698202+3494728+1433136+202288=7828354 ✓

## 2. 副定理

**球面充填**: 互換な境界球面はすべて実現される(n=2 全数検証:
互換 82 = 実現 82; 一般証明 = 指定 1 点の上閉包が最小充填、
中間点付け替え+互換性)。

**境界分類**: 境界 ↔ 最小充填 m(極小点がすべて面点な元)↔
**面点部分半順序集合の反鎖**。B(3) = 4,829,136 は直接 census と
56 点 poset の反鎖数え上げの独立 2 経路で一致(二重検証)。

**median シリンダー**: χ(k) = (φ∧¬k)∨(k∧φ′)∨(φ∧φ′) は同一境界の
φ,φ′ を結び、全 2n 面で k-定数。第三項は必須(自由 De Morgan 代数に
排中律がないため)。Birkhoff–Kiss 1947 の median の変種。

**数え上げ(OEIS 未登録、2026-07-30 照合)**:
B(n) = 4, 82, 4829136; 単元ファイバー数 2, 28, 2698202;
最大サイズファイバー数 2, 16, 25286 ほか。

## 3. 文献ポジション

- **最近傍**: Doré–Cavallo–Mörtberg "Automating Boundary Filling in
  Cubical Type Theories" (LMCS 22(2):28, 2026) — 同じ DM(n) で境界から
  充填を**探索**。解集合の分類・数え上げ・median 構造はなし(彼らの
  PPM 表現は解集合について自認的に lossy)。§4.3 の「consistent な
  代入」の微妙さを、本定理の対角点=自由ブール自由度が正確に解決。
- 区間サイズの数え上げ: Pawelski arXiv:2311.11744(D_7 の区間
  カーディナリティ計算; 構造定理はなし)。
- 対比: **Dedekind 部分言語(対合なし)では全点が面点で D = ∅、
  ファイバーは常に単元** — ブールファイバーは De Morgan 固有の現象
  (対合が生む「見えない対角」の定量化)。
