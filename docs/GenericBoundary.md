# Generic boundary 胞体と立方体 presheaf の実現(証明ノート、2026-07-28)

## 0. 位置づけ

strict-layer 論文(docs/paperC)は「generic ループの strict 層 = 境界潰し
表現可能関手(De Morgan 球面)のウェッジ」を示し、**generic boundary
胞体**の場合を open として明示した(strictlayer.tex, Remark
"Boundaries; the unpointed refinement")。本ノートはこれを解く:

**主定理(realization 論文の主定理)**: 胞体的文脈(𝔻 上の computad:
generic 頂点・generic 辺・…・generic n-胞体を境界整合的に並べた文脈)の
純粋再パラメータ化層 /≡alg は、その computad の**立方体 presheaf 実現**
(表現可能関手たちを境界接着で貼った colimit)に自然同型。とくに
単一の generic-boundary n-胞体では**潰しのない完全な表現可能関手**
𝔻(−,[n]) が実現される。ループの球面(strict-layer 論文)は「境界を一点
computad に接着した」特殊例として回収される。

## 1. 機械証拠第1弾(LibGenBoundary.lean、全 guard 通過)

文脈: 頂点 a00 a01 a10 a11、辺 p q r s、Q : PathP (⟨i⟩ Path A (r i)
(s i)) p q(generic boundary の generic 正方形)。

1. **接着方程式(presheaf の attachment がすべて定義的)**:
   ⟨j⟩Q(0)(j) ≡ p、⟨j⟩Q(1)(j) ≡ q(pathP の papp 端点崩壊が格納
   endpoint = 辺そのものを返す)、⟨i⟩Q(i)(0) ≡ r、⟨i⟩Q(i)(1) ≡ s
   (内側 papp の端点注釈 = 再パラメータ化された辺)。
2. **角**: ⟨i⟩⟨j⟩Q(0)(0) ≡ 定数 a00(境界を 2 段通過して頂点へ)。
3. **ウェッジ潰しの消滅**: 旧退化 square ⟨i⟩⟨j⟩Q(0)(j) は定数でなく
   **辺 square ⟨i⟩⟨j⟩p(j) に等しい** — 面因子化射の像は一点でなく
   境界層(辺の strict 層)に着地する。相異なる退化像は**型ですでに
   分離**される(p-square と q-square は型が違う)。
4. **DM 則は generic boundary でも strict**: 吸収
   ⟨i⟩⟨j⟩Q(i)(j∧(j∨i)) ≡ Q が完全な square 型 SqB で成立。
5. **転置は型横断の演算として存在**: ⟨i⟩⟨j⟩Q(j)(i) は辺を入れ替えた
   square 型に well-typed(対称は「同型間の作用」であり同一型の
   同一視ではない — ループの場合に転置が「分離」として現れたことの
   正しい一般化)。

## 2. 証明計画

- 補題(本体値): generic boundary では body 値は「頂点変数/辺 spine
  e(χ)/完全 spine Q(φ)(ψ)」のいずれかで、面因子化組は対応する
  境界 spine と**同一の値**(attachment)。
- 型付き分類: 立方体の型(境界データ)ごとに層別し、
  「型 = ∂ への写像、立方体 = その持ち上げ」という presheaf 的
  再定式化で colimit との比較写像を構成。単射性は C_n 論法
  (convNe)+型分離。全射性は構文的観察。
- 予想(要検証): 同一境界型内の相異なる非退化組は存在しない見込み
  (境界保存摂動 D は吸収で消える — 自由 DM の吸収律の考察を精密化)。
  成立すれば「型付き分類は表現可能関手の element ごとに一点」で
  実現定理が最も綺麗な形になる。
- 一般 computad・一般 arity への帰納(辺→square→n-胞体)。

## 3. 一意性予想の反証と、実現定理の正しい形(2026-07-28 追記)

### 3.1 反証(機械確定)

**一意性予想(§2)は偽**。反例: 自由 De Morgan 代数で
φ₁ = i∧¬i と φ₂ = (i∧¬i)∧(j∨¬j) は**相異なる**
(φ₂ が吸収されない: i∧¬i ≰ j∨¬j — clause {i,¬i} は {j} も {¬j} も
含まない)が、4 辺への 1 変数制限はすべて一致する
(i-辺: 両者 0; j-辺: 両者 i∧¬i)。よって
S(φ₁, j) と S(φ₂, j) は**同一の境界型**
PathP (⟨i⟩ Path A (r(i∧¬i)) (s(i∧¬i))) p p
に住み、かつ非退化 spine として**分離**される。
機械証拠: `gbFill1D`・`gbFill2D`(同一型の 2 充填)+負 guard(分離)。

**新定理(充填の非一意性)**: strict 層において、境界は充填を高々
一つには決めない — 同一境界の相異なる strict 充填が存在する。
(層別「境界 ↦ 充填集合」は単射でない; 制限写像
DM(i,j) → DM(j)²×DM(i)² の非単射性の幾何的発現。)

付随する正の補題(機械: `gbAbsorbPerturbD`): 最小の辺消失元
D₀ = i∧¬i∧j∧¬j による ∨-摂動は常に吸収される(D₀ ≤ φ が全ての
φ≠0 で成立 — D₀ の clause は全 literal 集合なので任意の clause を
含む)。すなわち「摂動が見える」のは φ₂ 型の ∧-構成のときで、
D₀ 自身を足しても新しい充填は生まれない。

### 3.2 作用の単射性と単一正方形の実現定理(値レベルで確定)

本体値の分類(generic boundary 版): 値は
(a) 頂点変数、(b) 辺 spine e(χ)(e ∈ {p,q,r,s}、χ 非端点)、
(c) 完全 spine Q(φ)(ψ)(両座標非端点)のいずれか。
組 ↦ 値 の対応で:
- 面因子化組 (ε,ψ) ↦ p/q の spine、(φ,ε) ↦ r/s の spine、
  (ε,ε′) ↦ 頂点 — **𝔻 における面合成と正確に一致**(接着方程式)。
- 相異なる組が同じ値になるのは「同一の面合成として一致する」場合のみ
  (辺 head p/q/r/s と頂点は互いに相異なる generic 変数; spine は
  K2 で分離)。

**定理(単一正方形の実現、証明スケッチ完了)**: generic boundary の
正方形 computad(頂点 4・辺 4・正方形 1)の純粋再パラメータ化層
/≡alg は、作用により **完全な表現可能関手 𝔻(−,[2]) と自然同型**
(潰しなし・単射)。ループの球面 𝔻(−,[2])/∂ は「境界を 1 点
computad に接着した」退化極限として回収される。

### 3.3 主定理の形(改訂)

一般の胞体的文脈(𝔻-computad; 複数の胞体が**辺を共有**しうる)では
ウェッジではなく **colimit(共有面に沿った表現可能関手の貼り合わせ
= computad の cellular presheaf)** が正しい主張:

  strict 層 ≅ colim_{胞体 c} 𝔻(−,[n_c])(接着 = 面合成の同一視)

- 単一胞体+generic boundary: 表現可能(§3.2 ✓)
- 単一胞体+退化 boundary(ループ): 球面(strict-layer 論文 ✓)
- 次のマイルストーン: **辺を共有する 2 正方形**の文脈で「貼り合わせが
  それ以上潰れない」probe(共有辺経由の同一視のみが成立し、
  異なる正方形の内部 spine は分離される)→ 一般 computad の帰納。
- 充填非一意性(§3.1)は実現定理と整合(表現可能関手の同一 boundary
  ファイバーが複数元を持つ、という𝔻 自身の事実の忠実な反映)であり、
  論文の独立した見どころになる(「strict な世界ですら充填は一意で
  ない」— Kan 充填の一意性 up to homotopy との対比)。

## 4. 辺共有 2 正方形: 貼り合わせ = 共有面、それ以上でもそれ以下でもない(2026-07-28 追記)

文脈: 頂点 6、辺 p/m/q + r1/s1/r2/s2、Q1 : PathP(⟨i⟩…) p m、
Q2 : PathP(⟨i⟩…) m q(**m を共有**)。機械証拠
(`LibSharedEdge.lean`、全 guard 通過):

**正(pushout の同一視が定義的に成立)**:
- 接着: ⟨j⟩Q1(1)(j) ≡ m、⟨j⟩Q2(0)(j) ≡ m(`seAttM1D`/`seAttM2D`)
- **胞体横断の面一致**: ⟨i⟩⟨j⟩Q1(1)(j) ≡ ⟨i⟩⟨j⟩Q2(0)(j)
  (`seGlueD`)— colimit の貼り合わせ写像そのもの。

**負(過剰同一視は起きない)**: 辺-1 元 E₀ = i∨¬i∨j∨¬j(Q1 側)と
辺-0 元 D₀ = i∧¬i∧j∧¬j(Q2 側)で「境界が完全に共有辺 m 上に載る」
正方形 S1 = ⟨i⟩⟨j⟩Q1(E₀)(j)、S2 = ⟨i⟩⟨j⟩Q2(D₀)(j) を作ると、
S1・S2・辺 square ⟨i⟩⟨j⟩m(j) は**同一型 Path (Path A a10 a11) m m**
に住み(対照 3 本)、**対ごとに分離**される(負 guard 3 本):
異なる胞体の内部物質は境界が一致しても融合せず、辺にも潰れない。

**定理(2 正方形の実現、スケッチ完了)**: この computad の strict 層
≅ **pushout 𝔻(−,[2]) ⊔_{𝔻(−,[1])} 𝔻(−,[2])**(共有面の face 射に
沿った表現可能関手の貼り合わせ)。単射性: head 解析(Q1/Q2/辺/頂点の
変数 head + spine 比較)、同一視の完全性: 接着方程式、全射性: 構文的
観察。∎(スケッチ)

**一般 computad への帰納(主定理)**: 胞体を 1 つずつ接着する
たびに「その胞体の表現可能関手を、境界指定の face 射に沿って colimit
に貼る」— 上の 2 正方形の議論が帰納段そのもの(接着 = attachment
方程式、非過剰性 = head 分離+充填非一意性の型内分離)。これで
主定理の証明部品はすべて機械証拠つきで揃った:

  **strict 実現定理**: 𝔻-computad の純粋再パラメータ化層 /≡alg ≅
  その computad の cellular presheaf(表現可能関手の colimit)。
