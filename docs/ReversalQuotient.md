# 定理: L = I/(x∼¬x) は非可縮かつ K(ℤ/2,1)(証明ノート、2026-08-02)

De Morgan・Kleene・Boolean の 3 立方体理論すべてで、型理論的モデル
構造において L → 1 は弱同値でない。Coquand の未出版ノート(2018)の §3–5 を対称「線」に適応し、有限検証部は機械 census で完結。

## 1. 設定

立方体理論 T ∈ {DM, KL, BA}。base 圏の射 f: J → I は名前を T(J) の
元に送る代入。I(J) = T(J)。L := Yon(x)/(x ∼ ¬x): L(J) = T(J)/±
(t ∼ ¬t)。型理論的 MS は Coquand §3 の trivial cofibration–fibration
分解(inc / comp^{k→l} の自由帰納構成)で定義される(cartesian の
記述は逐語的に一般の T へ — comp の方向 k≠l ∈ I(J) を許すのみ)。

## 2. 不変量 P′

**定義**: 正方形 c(x,z) が線 a(x), b(x) を**対称に**結ぶ ⟺
c(x,0)=a, c(x,1)=b(または逆)かつ c(¬x,z) = c(x,z)。
P′(A) ⟺ 任意の対称線 a(x)=a(¬x) が対称正方形の有限列で定数線に
結ばれる。

注(quotient 上の対称性): L では胞体は軌道 [t] なので
[t]∘σ_x = [t] ⟺ t∘σ_x ∈ {t, ¬t}。

## 3. 補題(切断移送)— Coquand Lemma 4.1 逐語

u: A → B が切断 v を持てば P′(A) ⟹ P′(B)。
(対称線 b ↦ vb 対称、A の対称列を u で写す。)∎

## 4. 命題(P′(A) ⟹ P′(T))— 帰納法

T の対称線は
(i) (σa, inc a): a は A の対称線 → P′(A) で処理。
(ii) (v(x,l), comp^{k→l}(a, φ, u, ⟨z⟩v(x,z))), k≠l ∈ I(x)。
対称性 = 自由構成子の等式 ⟹ k∘σ = k, l∘σ = l, a 対称, φ∘σ = φ,
u∘σ = u, v(¬x,z) = v(x,z)。

**新規の注意 1(方向集合の拡大)**: σ_x-固定な I(x) の元は
- DM/KL: {0, 1, x∧¬x, x∨¬x}(cartesian の {0,1} より大)
- BA: {0, 1}
いずれでも以下は変わらない。

**新規の注意 2(退化ケースの排除)**: restriction 規則の
「kg=lg なら u_k g」「φg=1 なら u_{[l]g}」ケースは、g = σ_x が
**T(J) の自己同型**であることから kg=lg ⟺ k=l(排除)、
φg=1 ⟺ φ=1(排除)。ゆえに対称性は必ず構成子等式で実現。

帰納ステップ: フレッシュ名 t で
c(x,t) := (v(x,t), comp^{k→t}(a, φ, u, ⟨z⟩v(x,z)))
は対称正方形(全データ対称)、c(x,l) = 元の線、c(x,k) = (v[k], a)
(t:=k で kg=lg ケース発火、= u_k = a)。a ∈ E(v[k]) は帰納的高さが
下がる対称線。帰納で (σa′, inc a′) 型に到達し P′(A) で結ぶ。∎

## 5. P′(1) と 3-out-of-2

P′(1) 自明。L → 1 が弱同値なら基点 1 → L も弱同値(2-of-3)。
その分解 1 → T → L で T → L は自明ファイブレーション ⟹ 切断あり。
命題より P′(1) ⟹ P′(T)、補題より P′(T) ⟹ P′(L)。

## 6. ¬P′(L) — 機械 census(有限・完全)

L の対称線 = 全ての線(3 軌道): [x](= [¬x])、[x∧¬x](= [x∨¬x])、
[0](= [1] = 定数)。L の対称正方形 = {t ∈ T(x,z) : t∘σ_x ∈ {t,¬t}}
— **2 変数自由代数の有限部分集合、全数列挙可能**。到達可能性:

| 理論 | 対称正方形数 | [x]→[x] | [x]→他 | [x∧¬x]↔const |
|---|---|---|---|---|
| De Morgan | 60 | 10 | **0** | 10+10 |
| Kleene | 32 | 6 | **0** | 6+6 |
| Boolean | 8 | 4 | **0** | (x∧¬x=0) |

**[x] のコンポーネントは 3 理論すべてで孤立** ⟹ [x] は対称列で
定数に到達不能 ⟹ ¬P′(L)。∎(§5 と併せ L → 1 は弱同値でない。)

補足(概念的説明): 被覆 □¹ → L のモノドロミー: [x] のリフトは
0→1(シート交換 = 奇)、[x∧¬x]・定数のリフトは端点同シート(偶)。
対称正方形はパリティを保存する — census の分離はその現れ。
(Remark 1 の接続救済 b = a(x∨z) は非対称: x∨z ≢ ¬x∨z、これも
census の「救済項 0」で機械確定済み。)

## 7. 系

1. 型理論的 MS ≠ test MS(BM: 3 理論とも strict test で test MS は
   空間、そこでは |L| ≃ 点 ⟹ L ≃ 1)。
2. 実現/三角化は Quillen 同値でない(左 Quillen 同値は cofibrant
   対象の可縮性を反映、L cofibrant(mono)、|L| 可縮、L 非可縮)。
3. **Kleene の場合は文献初**(2018 の括弧書き以外に言及皆無)。
   Boolean も明言(Coquand)のみで証明は初。

## 8. L ≃ K(ℤ/2, 1) の同定

**定理**: 3 理論すべてで p : □¹ → L は(uniform)ファイブレーション
であり、□¹ は可縮、ファイバーは離散 ℤ/2。したがって L の fibrant
replacement のループ対象は離散 ℤ/2 に弱同値、πₙ = 0 (n≥2)、
**L ≃ K(ℤ/2, 1)**。

**ファイブレーション性の証明(シート転送)**: 依存表現では
E(v) = p⁻¹(v) = {t, ¬t}(自由性定理により 2 元、どのレベルでも
固定なし)。箱データ (v ∈ L(J⁺), k≠l ∈ I(J), u_k ∈ E(v[k]),
ψ ≠ 1, 整合族 u) に対し:
1. v のリフト T ∈ T(J⁺) で T[k] = u_k なるものが**一意に存在**
   (2 つのリフト T, ¬T のうち丁度一方; T[k] = ¬T[k] は自由性に反する)。
2. comp^{k→l}(u_k, ψ, u) := T[l] と定義。
3. **チューブ強制補題**: ψg = 1 なる g: K → J に対し、チューブ胞体
   u_{g⁺}(g⁺: K⁺ → J⁺、ψp g⁺ = 1 ✓ データに含まれる)は
   u_{g⁺}[kg] = u_{[k]g} = u_k g = T[k]g = (Tg⁺)[kg]
   ([k]∘g = g⁺∘[kg] の自然性)を満たし、自由性(レベル K⁺ で
   固定なし)から **u_{g⁺} = Tg⁺ が強制**される。よって
   u_{[l]g} = u_{g⁺}[lg] = (Tg⁺)[lg] = T[l]g = comp の [l]g-制限 ✓
   (ψ 上の一致条件)。
4. **uniformity**: 制限 g(kg≠lg, ψg≠1)に対し、Tg⁺ は vg⁺ の
   リフトで (Tg⁺)[kg] = u_k g を満たす一意のもの ⟹
   comp(...)g = T[l]g = comp(u_k g, ψg, ug⁺) ✓ 構成の自然性そのもの。
5. comp^{k→k} = u_k ✓(T[k] = u_k)。

(機械検証: 自由性は m ≤ 3 の全レベル census で確認済み(§関連:
自己双対 0)— 構成の全等式は 1–5 の一般証明で閉じる。)

**可縮性**: □¹ は接続で可縮(c(x,z) = x∧¬z: z=0 で id、z=1 で 0)。

**同定**: ファイブレーション p、全空間可縮、ファイバー離散 ℤ/2 の
ファイバー列より Ω(L̂, ℓ₀) ≃ ℤ/2(離散)、πₙ(L̂) = 0 (n ≥ 2)。
基点は唯一の頂点 ℓ₀([0]=[1])。よって L ≃ K(ℤ/2,1)。∎

**意義**: 偵察 §11 の通り、L の実際のホモトピー型の同定は現在の
全主張(folklore 含む)を超える。物語としても完全: 実現(可縮)と
モデル構造(K(ℤ/2,1))の乖離が、**商が「軌道空間」でなく「ホモトピー
商」を計算してしまう**ことの正確な表現になる。§6 のパリティ分離は
π₁ = ℤ/2 の組合せ的影。
